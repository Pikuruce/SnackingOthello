# SnackingOthello

3Dオセロゲーム「SnackingOthello」のソースコードです。PythonとPanda3Dを使用して制作しています。

## ゲーム概要

通常のオセロに「自分のクッキーを食べる」という独自のルールを追加したゲームです。

白猫と黒猫のキャラクターが、クッキーを使って対戦します。

### ゲームモード

- **オフライン対戦** — 1台のPCで2人対戦できます。
- **オンライン対戦** — LAN内の別々のPCから対戦できます。6桁のルームコードを使用して接続します。
- **チュートリアル** — ゲームのルールや操作方法を確認できます。
- **リプレイ** — 保存した試合の記録を再生できます。

### ゲームルール

基本的なルールは通常のオセロと同じですが、次の独自ルールがあります。

- 通常のオセロと同様に、相手のクッキーを挟んで裏返すことができます。
- 自分のクッキーを1つ食べることができます。
- 食べたクッキーの数を記録し、対戦に反映します。

## 操作方法

### ゲーム中の操作

| 操作 | キー |
|---|---|
| カーソル移動 | `↑` `↓` `←` `→` |
| 決定・クッキーを置く | `Enter` |

※画面やゲームモードによって操作できる内容が異なります。

- **言語:** Python

### 必要な環境・ライブラリ

| 区分 | 項目 | バージョン / 備考 |
|---|---|---|
| **言語・ツール** | Python | 実行環境 |
| | uv | パッケージ管理 |
| | make | ビルド自動化 |
| **ライブラリ** | panda3d | ゲームエンジン |
| | nuitka | コンパイラ / ビルド用 |

※実際に使用するライブラリのバージョンは、プロジェクトの依存関係設定を参照してください。

### 起動

プロジェクトのルートディレクトリで、以下のコマンドを実行してください。

```bash
make run
```

または

```bash
uv run main.py
```

Pythonと必要なライブラリがそろっていれば、`main.py` を実行することで起動できます。

### ビルド

```bash
make build-windows
```

Windows用の`.exe`ファイルを生成します。

```bash
make build-macos
```

mac用の`.app`ファイルを生成します。

## オンライン対戦

LAN内の端末同士でオンライン対戦ができます。

### 接続方法

1. ホスト側でオンライン対戦を開始します。
2. 表示された6桁のルームコードを確認します。
3. クライアント側でルームコードを入力します。
4. 接続が完了すると対戦が開始されます。

オンライン対戦ではTCP通信を使用してゲーム中の操作情報を送受信します。また、UDP通信を利用してLAN内のルームを検索します。

※オンライン対戦には、両方の端末が同じLANに接続されている必要があります。

## リプレイ

対戦内容をJSON形式で保存し、後から再生できます。

- 対戦中の操作を記録します。
- 保存したリプレイを読み込んで試合を再生できます。
- チュートリアルでもリプレイデータを利用しています。

プレイヤーが保存したリプレイは、プロジェクトのルートディレクトリにある`snacking_othello_saves/`に格納されます。

## ディレクトリ構成

```text
SnackingOthello/
├── main.py
├── config.yaml
├── icon.ico
├── assets/
│   ├── font/
│   ├── images/
│   ├── objects/
│   ├── replays/
│   ├── sounds/
│   └── sprite_sheets/
├── lib/
│   ├── utils/
│   └── src/
│       ├── components/
│       ├── composables/
│       ├── networks/
│       ├── pages/
│       └── game.py
└── snacking_othello_saves/
```

- `assets/font/` — ゲーム内で使用するフォント
- `assets/images/` — UIや背景などの画像
- `assets/objects/` — 3Dモデルなどのオブジェクト素材
- `assets/replays/` — チュートリアル用のリプレイデータ
- `assets/sounds/` — BGMや効果音
- `assets/sprite_sheets/` — キャラクターなどのスプライトシート
- `lib/src/components/` — ゲーム内の各種コンポーネント
- `lib/src/composables/` — ゲーム進行や共通処理
- `lib/src/networks/` — LAN検索やTCP通信などのネットワーク処理
- `lib/src/pages/` — タイトル画面やゲーム画面などのページ
- `lib/utils/` — 設定ファイルやアセットパスなどのユーティリティ
- `snacking_othello_saves/` — プレイヤーが保存したリプレイデータ
